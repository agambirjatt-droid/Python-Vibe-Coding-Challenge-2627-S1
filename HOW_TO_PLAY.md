# Court Clash

Fast local two-player basketball in a polished, original arcade broadcast style. The court, animated players, ball, crowd, scoreboard, shot meter, effects, and audio are generated by Python. It runs without downloaded art or AI models.

## Start the game

Open a terminal in the folder containing `main.py`, then run:

```powershell
python -m pip install -r requirements.txt
python main.py
```

If Windows does not recognize `python`, use `py` in its place. The game opens in a resizable window; press **F11** for fullscreen.

## Controls

| Action | Blue City | Red Storm |
| --- | --- | --- |
| Move | A / D | Left / Right arrows |
| Jump | W | Up arrow |
| Sprint | E | Right Shift |
| Shoot | Hold F, release to shoot | Hold J, release to shoot |
| Dunk near the rim | G | K |
| Steal | S | H |
| Crossover | Q | U |
| Timeout | T | Y |

Time the shot release in the green section of the meter. Three-point shots have a smaller green window. When the ball is loose, move your player so the animated player reaches it with both arms.

## Match details

- Four one-minute quarters, halftime side switching, and 20-second overtime periods when the score is tied.
- Twelve-second shot clock, timeouts, steals, blocks, rebounds, three-point streaks, and a final box score.
- **P** pauses, **C** opens controls, **M** toggles sound, **R** rematches after the final buzzer, and **Esc** quits.

## Library

- `pygame-ce` for the game window, input, timing, graphics, and audio.
